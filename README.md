# Brain Hill

## Project files
- `index.html` — main application entry point for GitHub Pages.
- `style.css` — styles extracted from the original HTML.
- `script.js` — inline JavaScript extracted from the original HTML.
- Other files in this package, if any, are retained from the supplied ZIP.

## Run locally
Keep the files together in the same folder and open `index.html` in a browser.

## Publish with GitHub Pages
1. Extract this ZIP.
2. Upload the project files and folders to the root of your GitHub repository.
3. In **Settings → Pages**, select **Deploy from a branch**, choose your main branch and `/ (root)`, then save.
4. Open the website URL shown in the Pages settings.

## Preservation note
The supplied application was originally a single HTML file. Its embedded CSS and inline JavaScript have been moved into separate files so the project is easier to maintain. This structural change can affect behavior in some apps, especially where scripts depend on inline execution order or HTML-specific attributes. Test the app's key features after extraction before using it in production.
